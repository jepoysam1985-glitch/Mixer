JEIANNE FM MIXER (APK)
1. Gumawa ng GitHub repo at i-upload LAHAT ng laman nito (kasama ang folder na .github).
2. Pumunta sa tab na Actions > Build APK > Run workflow (kusa rin itong tatakbo kapag nag-upload).
3. Pagkatapos (mga 5-10 min), buksan ang run > Artifacts > JeianneFM-APK > i-download at i-install.
4. Sa app: pindutin ang MIC > Allow. Ilagay ang encoder settings. GO LIVE.
Walang relay at walang Vercel na kailangan.
